# 🏛️ (Архив) Инфраструктура на базе Selenoid + GGR

Эта папка содержит устаревшую конфигурацию инфраструктуры для автоматизации на базе Aerokube Selenoid. 
Подход с балансировщиком GGR и Nginx идеален для распределения нагрузки между множеством физических серверов, но избыточен для одного VDS.

> **Статус:** Разработка и поддержка бесплатных образов Selenoid официально прекращена разработчиками (Aerokube) в конце 2024 года. Код сохранён исключительно в целях обратной совместимости. Настоятельно рекомендуется использовать Selenium Grid 4.

## Структура конфигурации

1. `1-selenoid` — настройка нод Selenoid.
2. `2-ggr` — балансировщик (Grid Router).
3. `3-ggr-ui` — UI интерфейс для балансировщика.
4. `4-selenoid-ui` — UI интерфейс для самой ноды.
5. `5-nginx-proxy` — прокси-сервер.

* `docker-compose.yml` — единый файл запуска этой инфраструктуры.
* `setup.sh` — стартовый bash скрипт для инициализации.
