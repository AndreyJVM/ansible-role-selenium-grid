# (Архив) Инфраструктура на базе Selenoid + GGR

Эта директория содержит устаревшую конфигурацию инфраструктуры для автоматизации на базе Aerokube Selenoid. 
Архитектура с использованием балансировщика GGR и Nginx целесообразна для распределения нагрузки между множеством физических узлов, однако считается избыточной для эксплуатации на единичном VDS.

> [!WARNING]
> Разработка и поддержка бесплатных образов Selenoid официально прекращена разработчиками (Aerokube) в 2024 году. Код сохранён в целях обратной совместимости. Настоятельно рекомендуется миграция на Selenium Grid 4.

## Структура конфигурации

1. `1-selenoid` — настройка нод Selenoid.
2. `2-ggr` — балансировщик (Grid Router).
3. `3-ggr-ui` — Графический интерфейс балансировщика.
4. `4-selenoid-ui` — Графический интерфейс ноды Selenoid.
5. `5-nginx-proxy` — конфигурация reverse-proxy.

* `docker-compose.yml` — единый манифест запуска легаси-инфраструктуры.
* `setup.sh` — стартовый bash скрипт для инициализации среды.
